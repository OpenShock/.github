# Getting help with OpenShock

GitHub issues are for bug reports and feature requests. For everything else, these are the
places to go:

| I want to...                                   | Go to                                                                                   |
| ---------------------------------------------- | --------------------------------------------------------------------------------------- |
| Set up a device or learn how something works   | The [OpenShock Wiki](https://wiki.openshock.org)                                         |
| Ask a question or get help with a problem      | The [OpenShock Discord](https://discord.gg/OpenShock)                                    |
| Report a bug or request a feature              | The issue tracker of the affected repository                                             |
| Report a security vulnerability                | Privately, as described in the [security policy](https://github.com/OpenShock/.github/blob/main/SECURITY.md). Never in a public issue.  |
| Report a code of conduct violation             | [admin@openshock.org](mailto:admin@openshock.org)                                        |
| Ask about my account or my personal data       | [admin@openshock.org](mailto:admin@openshock.org)                                        |

Before opening an issue, please search the existing ones and check that you are running the
latest release.

Not sure which repository a bug belongs to?

- Website at `openshock.app` looks or behaves wrong: [Frontend](https://github.com/OpenShock/Frontend/issues)
- API responses, accounts, shares, device connectivity to the server: [API](https://github.com/OpenShock/API/issues)
- The hub itself, flashing, Wi-Fi setup, radio: [Firmware](https://github.com/OpenShock/Firmware/issues)
- Documentation: [Wiki](https://github.com/OpenShock/Wiki/issues)

OpenShock is maintained by volunteers in their spare time. We read everything, but we cannot
promise response times for general support.
